Joinly foundations

Look: “quiet classroom” — cool neutral ground, one confident blue for action, status colours that always come with an icon and words. Built for a phone held up in front of a class: large type, high contrast, 48 dp targets.

Colour — light · dark

Each chip: light theme on the left, dark on the right. Components only reference tokens (var(--c-…)), never hex. The QR always renders black on white in both themes.

Principles in the system

One primary action, in thumb reach

Bottom bar, extended FAB or the bottom of a sheet. Never top-right.

Errors in place

One sentence: what happened + what to do, on the screen where it happened.

Skeletons, not spinners

Lists and cards load as skeletons; spinners only inside buttons.

Never colour alone

Status = icon + text (dot “Joining open”, lock “Joining closed”).

RTL-ready

Logical properties (inline-start/end), mirrored back/chevron icons; codes stay LTR.

Dark-ready

Every colour is a token; flip the Dark tweak on any board to preview.
